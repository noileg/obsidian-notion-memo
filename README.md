# Notion Memo Sync（obsidian-notion-memo）

AIが一切介在しないメモを持つためのObsidianプラグイン。このプラグインを入れたvault内の
メモ（.mdファイル全部）を、Notion上の専用ページと双方向に同期する。

## 背景

個人用の自動化パイプライン「クロコ」（Notion + Gemini + Claude Codeで動く）を運用している。
スマホでのメモをNotion AIチャット経由で書くのが重い・使いにくいという不満から、
Obsidian（ノートアプリ）でスマホから気軽に書きたい、という要望が発端。

深掘りした結果、本当のニーズは「AIが一切介在しないメモを持ちたい」ことだと分かった。
そのため、このプラグインが送受信する経路には**要約・分割・書式変換のようなAI処理を
一切挟まない**（プレーンテキストの段落をそのまま右から左へ運ぶだけ）。

設計の経緯・決めた理由は`クロコ関係\クロコ本体\記録\検討中_Obsidianメモ連携.md`に
まとまっている（クロコ側のリポジトリ）。

## 仕組み

- **対象は「このプラグインが有効なvault」全体。** フォルダによる絞り込みはしない
  （専用vaultを用意する運用が前提）。
- 保存すると数秒後（デバウンス）に自動でNotionへ送信される（設定でオフにできる）。
- Notion側の親ページ配下に、メモごとに1つの子ページとして格納される。
- Notion側の変更は自動では降ってこない。コマンドパレットの「Notionから同期する」か、
  設定タブの「今すぐ同期」ボタンで取り込む。
- メモとNotionページの対応づけは、各ファイルのフロントマター（`notion_id`）で持つ。
  共有DBは無い。
- 本文はプレーンテキストの段落（空行区切り）としてやり取りする。見出し・リスト等の
  リッチな書式は今のところ変換しない。

## 設定

1. Notionでintegrationを作り、「Obsidianメモ置き場（同期用）」ページに接続する
   （[Notion Integrations](https://www.notion.so/my-integrations)）。
2. このプラグインの設定タブにトークンを貼る。
3. 親ページIDは既定値（「Obsidianメモ置き場（同期用）」のID）が入っている。変える場合のみ書き換える。

## 開発

```
npm install
npm run dev    # ウォッチビルド
npm run build  # 型チェック + 本番ビルド（main.js を出力）
```

`main.js` はビルド生成物なのでリポジトリには含めない（`.gitignore`）。
